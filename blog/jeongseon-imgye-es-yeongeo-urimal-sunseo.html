영어 문장을 우리말 순서대로 쓰는 아이에게는 '누가 → 한다 → 무엇을' 순서를 카드로 직접 배열해 보게 하는 것이 가장 빨라요. 우리말은 '나는 학교에 간다'처럼 동사가 맨 뒤에 오지만, 영어는 I go to school.처럼 동사가 주어 바로 뒤에 와요. 단어를 많이 알아도 이 순서 차이를 몸으로 익히지 않으면 문장을 쓸 때 우리말 순서가 먼저 나와요. 임계초등학교 영어 수업 내용과 평가 방식은 영어 선생님 안내를 기준으로 확인해 주세요.

한눈에 보기
  • 영어 기본 순서: 누가 → 한다 → 무엇을
  • 우리말은 동사가 끝, 영어는 동사가 앞쪽

우리말과 영어 순서 비교

우리말우리말 순서대로 쓴 영어바른 영어
나는 사과를 좋아해.I apples like.I like apples.
그는 축구를 해.He soccer plays.He plays soccer.
우리는 책을 읽어.We books read.We read books.

세 문장 모두 '무엇을'과 '한다'의 자리가 바뀌어 있어요. 아이에게 이 차이를 표로 직접 보여 주면 이해가 빨라요.

학습 예시: 단어 카드 배열

아래는 집에서 해 보는 방법을 보여 주려고 만든 예시예요.

  1. 카드 만들기 — 누가(파란색), 한다(빨간색), 무엇을(초록색)으로 색을 나눠 단어를 적어요.
  2. 색 순서 정하기 — 파랑 → 빨강 → 초록 순서로 놓는다고 알려 줘요.
  3. 문장 만들기 — 카드를 골라 순서대로 놓고 소리 내어 읽어요.
  4. 바꿔 보기 — 한 장만 다른 카드로 바꿔 새 문장을 만들어요.

쓰기 전에 말하기

문장을 쓰기 전에 먼저 소리 내어 말해 보게 하세요. 입으로 여러 번 말한 순서는 쓸 때도 자연스럽게 나와요. 처음에는 세 단어짜리 짧은 문장으로 시작하고, 익숙해지면 to school, in the park 같은 말을 뒤에 붙여요.
